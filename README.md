## Proyectos

**Demo en vivo:** [Escuela Forma · reservas de talleres](https://rosmery-gallardo.github.io/taller-reservas-web/) · **Portfolio:** [Vital 360](https://rosmery-gallardo.github.io/P3ROSMERY/)

- **[taller-reservas](https://github.com/rosmery-gallardo/taller-reservas)**: reservas de talleres con Laravel. Web MVC con Blade y Sass, API REST, control de aforo con transacciones y tests con PHPUnit.
- **[taller-reservas-web](https://github.com/rosmery-gallardo/taller-reservas-web)**: front en Angular (signals, formularios reactivos, HttpClient) que consume la API anterior. Diseño inspirado en la Bauhaus. **[Ver demo](https://rosmery-gallardo.github.io/taller-reservas-web/)**
- **[gencat-appointment-notifier](https://github.com/rosmery-gallardo/gencat-appointment-notifier)**: bot en Node.js y Playwright que revisa una web de cita previa cada 15 minutos y avisa por Telegram cuando aparece una fecha nueva.
- **[google-apps-script-tools](https://github.com/rosmery-gallardo/google-apps-script-tools)**: herramientas en Google Apps Script para automatizar el registro y el seguimiento de casos (Sheets API, Calendar API).
